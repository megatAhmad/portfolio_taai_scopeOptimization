System Flow Overview

Process Phases Description

Detailed breakdown of each phase in the MWCS pipeline.

Phase 1: Data Upload

User uploads Excel workbook containing maintenance work items.

  • Schema detection
  • Column validation
  • Data preview (10 rows)
  • Supporting dataset loading

Phase 2: Rule Configuration

Define categorization rules using the visual rule builder.

  • Numeric comparisons
  • Text matching & regex
  • Date operations
  • Lookup & aggregation
  • IF-THEN-ELSE chains

Phase 3: Processing

Execute rule evaluation and generate justifications.

  • Logic engine evaluation
  • Rule priority handling
  • AI justification (Claude/GPT)
  • Confidence scoring

Phase 4: Categorization

Assign final status to each work item.

  • ACCEPTED - Approved for execution
  • REJECTED - Not approved
  • RECONSIDER - Manual review needed

Phase 5: Export

Download results with full audit trail.

  • Excel (.xlsx) with formatting
  • CSV (UTF-8) for data tools
  • JSON for integration
  • Audit metadata included
